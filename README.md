# market-ledger-posts

Public image and video host for the Instagram account `the_market_ledger_` (posted through Buffer).

- `tools/make_post.py` renders a 6-slide carousel and a 9:16 Reel from a JSON spec (`tools/spec_example.json`).
- Each post lives in a dated folder: slides (`slide1.png` ...), `reel.mp4` and `caption.txt`.
